## Workflow
- Verify the requester's identity using the simulation's security procedures.
- Consult the company Knowledge Base and follow applicable guidelines.
- Use the authorized administration and remote-support tools.
- Record actions, observed outcomes, and unresolved checks.
- Do not infer root cause beyond the evidence.

All employee details are intentionally omitted from this public portfolio.
