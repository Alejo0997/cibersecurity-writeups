# INC0012847 — Shared Drive Unavailable for Remote Employee

**Environment:** Service Desk Simulator (training)  
**Status:** Resolved (reported).

## Symptoms
A remote employee could not open a shared drive and received a network-path error. Internet and email worked, but mapped drives appeared disconnected.

## Actions performed
1. Verified the employee's identity.
2. Consulted the company Knowledge Base and followed the documented troubleshooting procedure.
3. Connected to the employee's workstation using the simulator's remote desktop tool.
4. Activated the VPN connection.

## Outcome
Access to the shared resource was restored after VPN activation, according to the trainee's report.

## Skills
Remote desktop support; VPN connectivity; shared network resources; knowledge-base-guided troubleshooting; incident resolution.

## Learning
Working public internet access does not necessarily imply connectivity to internal network resources. Check the required VPN connection before changing share permissions.
